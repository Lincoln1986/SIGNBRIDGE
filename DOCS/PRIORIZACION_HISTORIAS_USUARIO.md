# Priorización de Historias de Usuario — SignBridge
**Actividad 3:** Aplicación al proyecto formativo  
**Proyecto:** App de Traducción LSC

## 📋 Planilla de Priorización, Importancia y Complejidad

| # | Historia de Usuario | Importancia | Complejidad | Prioridad |
| :-: | :--- | :---: | :---: | :---: |
| **1** | Como persona no oyente o persona oyente, quiero poder crear una cuenta en la aplicación, para acceder a las funciones de traducción de forma personalizada. | Alta | Media | HIGH |
| **2** | Como usuario registrado, quiero iniciar sesión con mis credenciales, para acceder a mi cuenta y retomar donde lo dejé. | Media | Baja | MEDIUM |
| **3** | Como persona no oyente, quiero que la app interprete mis señas a través de la cámara y las convierta en texto, para comunicarme con personas que no conocen la lengua de señas. | Alta | Alta | HIGH |
| **4** | Como persona no oyente, quiero personalizar mi avatar (piel, ropa, género) para sentirme representado durante las traducciones. | Media | Media | MEDIUM |
| **5** | Como usuario, quiero cambiar mi contraseña de usuario por si llego a olvidarla no perder mi cuenta. | Alta | Baja | HIGH |
| **6** | Como usuario, quiero poder enviar mi opinión de cómo me siento con la aplicación para poder recibir mejores actualizaciones. | Media | Baja | MEDIUM |
| **7** | Como usuario, quiero enviar un ticket de soporte visual o por texto para recibir ayuda cuando tenga un problema. | Media | Baja | MEDIUM |
| **8** | Como persona oyente, quiero escribir un texto en la app y ver cómo se traduce a lengua de señas mediante el avatar, para comunicarme con personas no oyentes. | Alta | Alta | HIGH |
| **9** | Como usuario registrado, quiero ver un historial de mis traducciones anteriores, para revisar conversaciones pasadas sin necesidad de repetirlas. | Media | Media | MEDIUM |
| **10** | Como usuario, quiero que la app realice traducciones básicas sin conexión a internet, para usarla en zonas con señal limitada o nula. | Alta | Alta | HIGH |
| **11** | Como usuario nuevo, quiero ver una guía rápida, para saber cómo usar la cámara correctamente. | Media | Baja | MEDIUM |
| **12** | Como estudiante de lengua de señas, quiero un buscador de palabras, para aprender señas individuales. | Alta | Media | HIGH |
| **13** | Como usuario, quiero consultar señas específicas de mi región para comunicarme de forma más natural según el contexto cultural. | Media | Media | MEDIUM |
| **14** | Como aprendiz de LSC, quiero poder disminuir la velocidad de las señas del avatar para entender mejor los movimientos complejos. | Alta | Media | HIGH |
| **15** | Como persona oyente, quiero dictar por voz lo que quiero decir para que el avatar lo traduzca a señas sin tener que escribir. | Alta | Alta | HIGH |
| **16** | Como usuario interesado, quiero publicar dudas sobre una seña para que expertos o la comunidad me ayuden a aclararla. | Baja | Media | LOW |
| **17** | Como usuario registrado, quiero exportar mis traducciones guardadas para compartirlas con terceros o tener un respaldo físico. | Media | Media | MEDIUM |
| **18** | Como usuario, quiero poder cerrar mi sesión para evitar que mi cuenta quede en otros dispositivos. | Media | Baja | MEDIUM |
| **19** | Como usuario con problemas de visión, quisiera un modo oscuro/claro para adaptar la interfaz a mis condiciones visuales. | Baja | Baja | LOW |
| **20** | Como usuario, quiero activar subtítulos en tiempo real, ajustar tamaño de texto, contraste y modo de interfaz para garantizar un entorno inclusivo y adaptable. | Alta | Alta | HIGH |
| **21** | Como usuario registrado, quiero poder eliminar permanentemente mi cuenta de la aplicación para asegurarme de que mis datos personales sean borrados del sistema. | Alta | Media | HIGH |
